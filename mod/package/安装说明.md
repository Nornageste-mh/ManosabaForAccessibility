## 这是什么

这是《魔法少女ノ魔女裁判》的**读屏无障碍补丁**，让使用屏幕阅读器的玩家也能游玩本作。

- **非官方**：与开发 **Acacia**、**Re,AER** 和发行 **Re,AER**、**CIRCLE LINE GAMES**（中文版）
  没有任何关系，也未获其授权或背书
- **仅限正版玩家**：请先通过 Steam 购买本作 —— **这个补丁是让你能玩上这款游戏，不是让你不必买它**
- 补丁**不修改任何游戏文件** —— 由 BepInEx 6 在运行时挂载，卸载就是删文件

## 装之前

- Windows 10 / 11（64 位）
- 游戏已安装，能正常启动
- 一个可用的读屏后端：**NVDA**（推荐）、或系统自带的 **SAPI** 语音

## 安装（仅限正版玩家）

1. 关闭游戏。
2. 到 Releases 下载 `ManosabaA11y-<版本>.zip`，解压。
3. 把解压出来的东西**整体**拷进游戏根目录 ——
   也就是有 `manosaba.exe` 的那一层。
   整包包括 `winhttp.dll`、`doorstop_config.ini`、`.doorstop_version`、`BepInEx\`、
   `dotnet\`、`nvdaControllerClient.dll`、`licenses\` 与几份说明文档；
   其中 `winhttp.dll`、`doorstop_config.ini`、`.doorstop_version`、`BepInEx\`、`dotnet\`
   **缺一样都起不来**，`nvdaControllerClient.dll` 缺了会没有 NVDA 朗读，
   `licenses\` 与说明文档只是随包附带。
4. 提示「是否合并 / 替换」时选**是**。
5. 启动游戏。听到「魔法少女ノ魔女裁判 无障碍补丁已加载」就说明通了。

### 第一次启动会慢

本作是 **IL2CPP**，BepInEx 6 的 Il2CppInterop 要在首次启动时生成
`BepInEx\interop\`（约 160 个程序集）。**第一次启动可能要等几十秒到几分钟**，
期间画面可能没有反应，这是在生成、不是卡死；生成完之后每次启动都正常。

生成失败的典型症状：`BepInEx\interop\` 里出现 **0 字节**的 dll。
处理：关掉游戏，删掉整个 `BepInEx\interop\`，再启动一次，然后看 `BepInEx\LogOutput.log`。

### 三条容易踩的坑

- `winhttp.dll`、`doorstop_config.ini`、`.doorstop_version` 和 `dotnet\`
  必须在**游戏根目录**
- `BepInEx\core\` 里的文件**一个都不能少**（本作是 BepInEx 6，不能混用 BepInEx 5 的 core）
- `nvdaControllerClient.dll` 放游戏根目录
  （原生 DLL 查找会**先看应用目录**；包里另外在 `BepInEx\plugins\manosaba_a11y\` 也放了一份）

### 已经装过别的 BepInEx 模组？

只需要两个文件：

- `BepInEx\plugins\manosaba_a11y\ManosabaA11y.dll`
- `nvdaControllerClient.dll` → 游戏根目录

**不要**覆盖对方已有的 `winhttp.dll` 和 `BepInEx\core\` ——
尤其不要拿 BepInEx 5 的文件覆盖 BepInEx 6 的（本作必须 BepInEx 6）。
如果对方也是 BepInEx 6，`Il2CppInterop.Runtime.dll` 以内容更新的那份为准即可。

装了什么就删什么。补丁不改动游戏本体逻辑，**不会留下任何残留**，存档也不受影响。

**按上面的步骤从零装的（本包是你唯一的 BepInEx）：**

只删这两样，**不要动**已有的 `winhttp.dll`、`BepInEx\core\`、`BepInEx\patchers\` 和 `dotnet\`：

- `BepInEx\plugins\manosaba_a11y\`
- `BepInEx\config\manosaba.a11y.reader.cfg`

`BepInEx\config\BepInEx.cfg` 里 `[Logging.Console]` 的 `Enabled` 改回 `true` 只是恢复控制台，不影响功能。

### 剧情跳转菜单（开发者功能，v0.1.0.0 起）

> ⚠️ 这是给开发/测试用的：会直接跳到没读过的剧情、破坏存档进度、可能剧透。
> 默认关闭，需要先在 `BepInEx\config\manosaba.a11y.reader.cfg` 里把
> 「其它 / 允许剧情跳转（开发者）」改成 `true`，再重启游戏。

用法：按 `Ctrl` + `Alt` + `Shift` + `F3` 打开菜单（会念当前剧本与总数），然后

| 按键 | 作用 |
|---|---|
| `↑` / `↓` | 上一个 / 下一个剧本（按 Name 顺序，共 440 个） |
| `PageUp` / `PageDown` | 往前 / 往后跳 10 个剧本 |
| `Home` / `End` | 跳到第一个 / 最后一个剧本 |
| `1`-`9` | 输入起始行号（最多 5 位，会念出来） |
| `Esc` / 退格 | 关菜单 / 清零行号 |
| `回车` / `空格` | 跳到「当前剧本 + 起始行」 |

「起始行」是剧本里的行号（0 = 从剧本开头）。一般用 0 就够；
要复现某个具体位置时才需要填。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `1`-`9` | 选择对应编号的选项 |
| `0` | 立刻停止朗读（沉默键） |
| **`=`** | 重读上一句剧情/选项（有配音的句子也会用 TTS 念出来） |
| **`Alt`+`Shift`+`F1`** | 进入 / 退出界面导航模式（**主键**） |
| `Tab` | 同上的备用键（⚠️ 标题画面里可能被游戏吃掉，见下） |
| **`F7`** | 切换语音后端（念出新的后端名） |
| `↑` `↓` | 上一项 / 下一项 |
| `←` `→` | 调整滑条 |
| `回车` / `空格` | 导航模式下激活控件；否则交给游戏推进剧情 |
| `Home` / `End` | 第一项 / 最后一项 |
| `PageUp` / `PageDown` | 切换面板组 |
| **`Esc`** | 关闭魔女手册 / 对话记录这类整页界面（并念「已关闭…」） |

### 为什么导航不是 Tab 了（实机反馈）

有玩家反馈：「主界面还没加载出来时按 Tab 有反应，主界面加载之后按 Tab 就没反应」——
标题画面出来后游戏自己把 Tab 当菜单键吃掉了。所以**主键改成 `Alt`+`Shift`+`F1`**
（游戏不会用这个组合），`Tab` 仍然保留为备用键，可以在配置里关掉
（`界面导航 / 同时允许 Tab`），也可以自己改 `导航开关键`。

### 听不到声音？先按 F7

如果机器上同时装了 **NVDA** 和 **争渡**（或其它读屏），补丁的「语音后端 = 自动」
会按 自动 → Tolk → NVDA → 争渡 → SAPI 的顺序挑第一个可用的 ——
**挑中 NVDA 时，如果你是争渡用户就会一句都听不到**。

启动时补丁会念「……语音后端 NVDA」告诉你当前用的是哪个；按 `F7` 循环切换，
每次都会念出新后端名（实测能从 NVDA 切到「争渡读屏」）。

**游戏原生占用的键**（模组不会去抢，也不要拿来当重读键）：
本作是 Naninovel，`Ctrl` 快进、`Enter` / `空格` / 鼠标左键推进、`Esc` 菜单。
补丁只在**界面导航模式**与**选项编号键**上接管输入，其余按键原样交给游戏。

## 现在能听到什么（v0.1.0.0 实测范围）

- ✅ **对话与旁白的逐句朗读**，对白会先报说话人名（例：「樱羽艾玛：——不对！」），旁白不报。
- ✅ 文本清洗：`<br>` 转停顿、`<ruby>` 读「正文（旁注）」、`<link>` 只读文字、
  其它富文本标签不念出来。
- ✅ **选项朗读与数字键选择**：选项出现时整组播报（「共 2 个选项。选项 1：……。选项 2：……。
  按数字键选择。」），按 `1`-`9` 选中后会先复述再执行。
- ✅ **加载播报**：点「新游戏」/切场景时黑屏加载阶段会念「正在加载。」，
  回答「为什么现在没反应」。
- ✅ **菜单 / 设置界面的中文名与当前值**：保存、读取存档、对话记录、系统设置、返回标题、
  关闭、打开菜单、自动播放、重播语音、各设置页签与滑条（主音量 / 音乐音量 / 文字显示速度 /
  语言 …）都有中文名，滑块会报百分比、下拉框会报当前选项。
- ✅ **审判辩论朗读**（实机跑完整段第 1 章审判，16 句连续）：辩论句整句到达即朗读，`<link>` 只读文字。
  辩论界面没有可靠的说话人信息，所以**辩论句不报名字**（避免张冠李戴）。辩论画面的「跳过辩论」按钮可导航。
  审判的倒计时与 HP 条不是可交互控件，导航读不到（暂时没有主动播报）。
- ✅ **魔女手册（图鉴）的中文名**：5 个页签（线索 / 人物 / 地图 / 规定 / 记录）、地图上 29 个地点
  （医务室 / 审判庭 / 图书室 / 火精之室 …，用的是游戏自己的本地化表）、上一页 / 下一页、出示证据、
  放大查看、关闭都能念出中文。页签组播报例：
  「导航模式。第 1 / 10 组：记录页签，1 项。全部 10 组：【记录页签 1 项】；规定页签 1 项；地图页签 1 项；
  人物页签 1 项；魔女手册 14 项；线索页签 1 项。」
- ✅ **有配音的句子完全安静**（v0.0.0.4 起，按要求默认如此）：游戏语音已经在念的台词，
  补丁不念正文、也不报名字（避免两路声音叠在一起）；想听文本按 `=`，会正常念出来。
  旧配置不会自动迁移，请确认 `BepInEx\config\manosaba.a11y.reader.cfg` 里 `有配音时也报说话人 = false`。
- ✅ **`=` 重读**：只退回「剧情文字 / 选项播报」，不会退回界面导航的「系统设置，按钮。2 / 5」。
- ✅ **完全没有 BepInEx 黑窗口**（v0.1.0.0 起）：包里带 `BepInEx\config\BepInEx.cfg`，把 `[Logging.Console] Enabled` 设成 `false`，控制台**从一开始就不会创建**，所以开局也不会闪一下黑窗；日志照旧写 `BepInEx\LogOutput.log`。
  - ⚠️ **如果你本来就有 BepInEx**：不要覆盖这个文件，只把你自己 `BepInEx.cfg` 里同一项改成 `false`。
- ⚠️ 魔女手册里**方向键逐项移动**：代码路径与标题菜单相同，但自动化合成扩展键不稳定，
  没有复测成功 —— 请自己按方向键确认一下；如有问题请把 `BepInEx\LogOutput.log` 发来。
- ✅ **打开魔女手册 / 对话记录时自动播报整页内容**（v0.0.0.8）：打开就念
  「魔女手册，线索页签。内容：……」；切到地图页会念
  「魔女手册，地图页签。内容：1F：会客厅、玄关大厅、审判庭入口过道、食堂、……」
  （只念当前楼层的地点，不夹角色名）。
- ✅ **`Esc` 直接关闭整页界面**（v0.0.0.8）：手册/记录页里按 `Esc` 会调用界面自己的关闭按钮
  并念「已关闭魔女手册。」。这条是为了绕开平台层的一个坑：手册打开时有一层全屏遮罩，
  平台层的「能不能点到」判定会把关闭按钮误判成不可达，于是**进去了出不来**。

## 审判议论的台词不自动朗读（v0.0.0.11 起）

魔女审判时的论战台词几乎全部带语音，所以默认**不自动用 TTS 朗读**（避免两路声音互相盖）。
但每一句都会进重读缓冲：**按 `=` 就能再听一遍这句台词的中文**。
想让它像普通对话一样自动读，去 `BepInEx\config\manosaba.a11y.reader.cfg` 把
「朗读审判议论」改成 `true`。

## 审判时「出示证据 / 选证物」（v0.0.0.9 起）

审判到要出示证据时，游戏会打开魔女手册并限制成只剩「证物」页，底下一排是**纯图标**的证物卡。
补丁会：

1. 自动把每张证物卡的**名字**念出来（做法是把卡片依次点一遍、读右侧标题，再点回第一张，你听不到过程，只会听到结果）；
2. 念「请出示证据。可选的证物共 N 件：1、…。2、…。按数字键选择。」；
3. `1`～`9` = **选中**这件证物（会复述名字），选中后可以继续按别的数字改选；
4. **`回车` 或 `空格` = 出示**（这一步必须你自己按，补丁不会替你提交）；
5. 游戏会弹「确定要提交此项证据吗？」——补丁会念出这句话和按钮「1、返回。2、是。」，
   `1` / `2` 选择。**「是」永远不会被自动按下。**

注意：证物件数超过 9 件时用 `PageUp` / `PageDown` 翻页；念列表时如果某件念成「证物 N」，
说明那一次的标题没读到（不影响你按数字键选它）。

## 配置

配置在 `BepInEx\config\manosaba.a11y.reader.cfg`，也可以装
[ConfigurationManager](https://github.com/BepInEx/BepInEx.ConfigurationManager) 在游戏里改。

配置分三组：

- **朗读** —— 朗读无配音剧情 / 无法判定时也朗读 / 朗读时带上说话人 / 朗读选项 /
  数字键选择选项 / 限时选择时长 / 沉默按键 / 重读按键 / 语音后端 / 朗读手机消息 / 手机表情贴纸
- **界面导航** —— 菜单键盘导航 / 按屏幕位置排序 / 只看可见控件 / 退出需确认 /
  需确认的控件名 / 排除的控件名
- **其它** —— 启动提示 / 界面诊断日志 / **文本语言**（跟随游戏、简体中文、日本語）

### 一定要先看一眼「文本语言」

本作的默认文本语言是**日文**（游戏目录 `manosaba_Data\StreamingAssets\config.json`
里 `available_text_lang` = `ja`、`zh-Hans`）。补丁默认「跟随游戏」，
如果你在中文环境玩、听到的是日文文本，就把这一项改成**简体中文**，
补丁会用 Naninovel 的 `ILocalizationManager.SelectLocale("zh-Hans")` 切过去。该功能已实机双向验证（切到简体中文读到中文、切到日本語读到日文）。

> 写在每一项说明里的实测数字（例如剧本行数、配音覆盖率）
> 是本补丁的可信度来源，**逐作都要重新测** —— 本作的数据见
> 仓库里的 `无障碍可行性验证.md`。

## 开发者面板（Ctrl+Alt+Shift+F3）为什么没反应

这是**试做功能**，默认关闭（配置 `BepInEx\config\manosaba.a11y.reader.cfg` 的
`允许激活开发者选项`）。实机查证结论：**正式发行版里游戏自己没创建调试管理器**
（`DebugOptionsBase.s_debugManager == null`），调试面板只是内存里的预制体、从未被实例化，
所以发行版按这个组合键不会有面板出现（那是开发构建/Editor 才有的东西）。
补丁保留了开关（打开后会把组合键接上、并尽力补建管理器与面板），但**不建议开启**：
它会扩大可达范围、可能剧透或搞坏存档体验。

## 地图上选择地点（v0.0.0.8 起）

审判和剧情里经常会出现「现在要去哪里」的地图（魔女手册的「地图」页，底部有 1F / 2F / 地下1F）。
以前这一步读屏玩家做不了，现在可以：

- 地图一出现，插件会立刻把**游戏允许你去的地点**从头到尾念一遍，例如
  「地图上可前往 8 个地点：在1F：1、会客厅。2、玄关大厅。3、食堂。4、医务室。5、淋浴房。
  6、往湖方向。在2F：7、娱乐室。在地下1F：8、牢房。按数字键选择。」
  名单直接来自游戏剧本，**不会把去不了的地方念成能去**。
- 直接按 `1`-`9` 选对应编号即可过去；这个界面里按错楼层不会出问题，插件会自动帮你点到正确楼层的那个地点。
- 名单超过 9 个地点时，用 `PageUp` / `PageDown` 翻页（插件会先念「第 2 页」这类提示再报新页的地点）。
- 正在选地点的时候，`Esc` 不会关掉手册（会念「请先选择一个地点。」）——因为这一关需要先做出选择，
  关掉会让剧情卡住。

顺带一提：**不在选择状态**、只是自己翻手册看地图时，`PageUp` / `PageDown` 仍然可以用来切换楼层查看。

## 低性能模式（v0.1.0.0 起是五档循环，默认关闭）

游戏卡的时候按 **`Alt` + `Shift` + `F2`** 一轮一轮往上加档，每按一次会念出当前档位：

| 按到 | 做了什么 |
| --- | --- |
| 关闭 | 什么都不改（并把之前改过的全部还原） |
| 轻度 | URP 画质降级 + 关掉柔边阴影（文字/立绘的阴影会消失） |
| 均衡 | 再降渲染分辨率、**窗口 0.85×**、质量等级最低、纹理半分辨率、关抗锯齿与阴影、LOD |
| 强力 | 再降到 0.5 渲染缩放、**窗口 0.70×**、纹理 1/4、关各向异性与实时反射、锁 30 帧、停粒子 |
| 极限 | **窗口 0.50× + 画面整个丢掉，只剩一个黑窗口**；另加强制最低 LOD/单骨骼、关所有后处理、**停所有动画**、锁 30 帧 |

- 每按一次都会播报「低性能模式：轻度/均衡/强力/极限」，回到「已关闭」时念「画面设置已还原」。
- **极限档不影响操作**：它是把 UI 图元的颜色刷黑（不是关 Canvas），所以点击与朗读都还在，
  剧情照样能推进。屏幕确实什么都没有，怕误触就把配置里的「允许极限档（画面全黑）」关掉。
- 想让它一直开着：配置里把「性能 / 低性能模式档位」设为某一档即可（旧版本的写法
  「保守/普通/激进」仍然认，会自动迁移成「轻度/均衡/强力」）。
- 每一类手段都能单独关：「降低 URP 画质」「关闭柔边阴影」「允许质量/纹理降级」
  「允许激进档专属手段」「允许极限档（画面全黑）」。
- **窗口分辨率从 v0.1.0.0 起算进档位**：均衡 0.85× / 强力 0.70× / 极限 0.50×（以原生分辨率为基准）。
  不想让窗口尺寸变，就关掉配置「性能 / 允许改变窗口分辨率」。
- 帧率长期低于 15 时只会提醒一句，**不会自动帮你切档**。
- 提醒：画面降级的收益取决于场景；另有一项恒定收益是插件自己的每帧开销（10~13ms → 2.5~5ms）。

## 「有 CG / 立绘 / 过场就卡」怎么办（v0.1.0.0 查证结论）

我们专门量过：这类卡顿是**主线程**瓶颈，把画面降级（渲染缩放、关阴影、纹理 1/4、窗口缩小）
**几乎没有帮助**（实测强力档 12.1 帧，关闭档 13.5 帧，属于噪声范围）。

- 唯一可能沾边的是「界面动画」：Animator 每帧求值要占主线程。但两轮测量结果互相矛盾
  （15.5 帧 / 8.1 帧，剧情位置不同会导致帧率在 8~15 之间乱跳），**证据不足**。
  所以只留了一个默认关闭的开关：「性能 / 停止界面动画（强力档起）」。
  想省主线程可以打开试；如果某段过场停住不动，把它关掉（极少数过场靠动画事件推进）。
- 剩下的卡顿来自游戏自己的逐字文本排版与界面重建，外部模组无法再优化。
- 如果只是想「听得到、能操作」，用**极限**档即可：画面全黑、画面开销归零，操作与朗读不受影响。
