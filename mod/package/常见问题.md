# 常见问题

> 发布包内文档之一。**跨作可复用**（玩家遇到的问题高度重复）。
> 逐作只需要补「本作特有」的那几条。

## 魔女审判时的台词为什么不自动朗读了（v0.0.0.11）

因为那些台词几乎全部带游戏语音，TTS 同时响会把语音盖住。
台词仍然会进重读缓冲：**按 `=` 可以再听一遍中文**。
如果你希望它像普通对话一样自动读，把 cfg 里的「朗读审判议论」改成 `true`。

## 装了没反应 / 游戏里一片安静

按顺序排查：

1. **先按 `F7`**。你的机器上可能同时装了 NVDA 和争渡，`语音后端 = 自动` 会按平台顺序
   挑中 NVDA；如果你平时用争渡，就会一句都听不到。按 `F7` 循环切换后端，
   每切一次都会念出新的后端名（`语音后端：争渡读屏` / `语音后端：SAPI` …）。这是 v0.0.0.2 新增的逃生键。
2. **看日志**。`BepInEx\LogOutput.log` 里有没有
   `语音后端就绪` 或 `无障碍补丁已加载`？
   - 完全没有这个文件 → BepInEx 没挂上，检查 `winhttp.dll`
     是不是在**游戏根目录**
   - 有文件但没有插件的行 → 插件版本号可能非法（含字母），
     看日志里有没有 `version is invalid`
3. **语音后端**。把配置里的「语音后端」依次钉死成 `SAPI` 试 ——
   如果 SAPI 能出声，说明是 NVDA 那条路的问题。
   注意：**钉死的后端不可用不会回退**，这是刻意的。
4. **中文语音**。SAPI 需要系统里装了中文语音包，
   否则会念成英文或者干脆不出声。设置 → 时间和语言 → 语音。

## 日志里有一行 `version is invalid`

`BepInPlugin` 的版本号含字母了。BepInEx 会**静默跳过整个插件**。
这不该出现在正式发布版里 —— 请反馈，这是打包 bug。

## 按 Tab 没反应 / 导航键是什么

**主键是 `Alt`+`Shift`+`F1`**（v0.0.0.2 起）。`Tab` 仍可用，但**本作标题画面出现后会
把 Tab 当自己的菜单键吃掉** —— 表现为「主界面加载前按 Tab 有反应、加载后没反应」。
两个键都能在 `BepInEx\config\manosaba.a11y.reader.cfg` 的「界面导航」组里改
（`导航开关键` / `同时允许 Tab`）。改坏了也不用重装：`同时允许 Tab` 留着就能救回来。

进入导航后会听见「导航模式，标题画面，共 5 项。退出游戏，按钮。1 / 5」；
`↑` `↓` 换项、`回车` 激活、再按一次 `Alt`+`Shift`+`F1` 退出。

## 台词朗读和游戏语音叠在一起

v0.0.0.4 起默认**有配音的行完全安静**：游戏语音已经在念的台词，补丁既不念正文、
也不报说话人名，两路声音不会叠在一起。想听文本按 `=`，会正常念出来。

- 不想要这种「安静」时：配置「朗读 / 朗读无配音剧情」保持开启、
  打开「朗读 / 有配音时也报说话人」即可让配音行也报名字（正文仍然交给游戏语音）。
- 旧配置不会自动迁移：升级后请看 `BepInEx\config\manosaba.a11y.reader.cfg` 里
  `有配音时也报说话人` 是不是 `false`。
- 拿不到「这行有没有配音」的判断时（例如剧本被改过），按「朗读 / 无法判定时也朗读」
  （默认开）处理：宁可多念一遍也不漏。

## 有配音的句子为什么没有朗读

这是有意为之（v0.0.0.4 起默认连名字也不报）。判定依据是游戏资源里的配音清单
（26,083 条 clip），按剧本行 id 精确匹配：命中的行正文交给游戏语音，TTS 不出声。
用 `=` 可以随时用 TTS 重读上一句，包括有配音的那些。

## 黑窗口（控制台）怎么关掉

默认启动后自动隐藏 BepInEx 的控制台窗口（只隐藏窗口，**不改 BepInEx.cfg**）。
需要看日志时把配置「其它 / 隐藏控制台窗口」关掉再启动。

## 标题 / 菜单里的按钮念不出名字，只念类型

v0.0.0.2 已经按实机取证给标题菜单、手机菜单、系统设置、画廊、对话记录里的控件做了中文名
（新游戏 / 读取存档 / 鉴赏模式 / 退出游戏 / 保存 / 读取存档 / 对话记录 / 系统设置 /
返回标题 / 主音量 / 文字显示速度 / 语言 …），滑条会报百分比、下拉框会报当前选项。

但如果某个界面里出现「只念类型、没有名字」，通常是这两类：

1. **魔女手册（WitchBook）的线索卡片** —— 页签与地图地点在 v0.0.0.4 已实机验证有中文名，
   但卡片本身的标题来自游戏图鉴文本，个别卡片可能仍然只有类型。
2. **存档槽** —— 220 个槽位文字都是 `<cspace=0.12em>NO DATA`，会被去重成同一句。

这是已知缺口，不是安装错误。

如果某个界面里**所有**控件都念不出来：

1. 打开配置「界面诊断日志」
2. 进那个界面，退出游戏
3. 把 `LogOutput.log` 里 `[UiNav]` 那些行发给我们

那里面是控件名、层级路径与朗读文本，**排查完请关掉**，否则日志会很大。

## 快进的时候不朗读

**这是设计如此** —— 快进期间每一行都念会刷屏。
松手停下来时，补丁会补念停在哪一句（配置「快进停止时补念当前句」）。

## 限时选择来不及选

配置「限时选择时长」可以拉长倒计时（默认比原版长）。

> **倒计时只能拉长，不能取消。** 到点会走「什么都不做」的沉默分支 ——
> 取消掉等于**删掉一个剧情分支**，那不是无障碍该做的事。
> 附注：本作剧本里 `timeout` 出现 0 次，实测**没有限时选项**，这条对当前版本是空转。

## 导航的时候会念到一堆无关的按钮

配置「排除的对象名」里加上那些控件的**对象名**（逗号分隔）。
匹配走**祖先链** —— 填容器的名字就能把里面整棵子树排除掉。

名字要从 `[UiNav]` 诊断日志里**实查**，不要凭感觉猜。

## 存档会被覆盖 / 退出游戏按错

- 「退出前二次确认」默认是开的：激活 `Button_Exit 类控件会先朗读一次确认，
  再按一次回车才真的退出，按方向键即取消。
- 存档槽现在会读「存档名 + 时间 + 章节」拼起来的结果，
  所以同一页的空槽位不会再念成 5 个一样的「无存档」。

## 会不会封号 / 算不算作弊

补丁**不修改游戏文件**，不联网，不注入游戏进程以外的任何东西。
但**请自行判断风险**：这是第三方工具，开发商没有背书。

## 支持盗版吗

**不支持。** 本补丁只面向已通过 Steam 购买本作的玩家。
它的意义是让你**能玩上**这款游戏，不是让你不必买它。

## 第一次启动特别慢 / 卡在启动界面（IL2CPP 特有）

本作是 IL2CPP，BepInEx 6 首次启动要生成 `BepInEx\interop\`（约 160 个程序集），
**几十秒到几分钟**都算正常，画面没反应不等于卡死。第二次启动就恢复正常。

如果一直很慢、或者 `BepInEx\interop\` 里有 **0 字节**的 dll：
关游戏 → 删掉整个 `BepInEx\interop\` → 再启动一次 → 看 `BepInEx\LogOutput.log`。

## 报错里有 `Il2CppInterop.Runtime` / `ClassInjector`（IL2CPP 特有）

说明包里的 `BepInEx\core\Il2CppInterop.Runtime.dll` 与生成 interop 的那份不一致。
把整个 `BepInEx\interop\` 删掉、用本包里的 core 重新启动一次即可。
## 按 Ctrl+Alt+Shift+F3 没有出现开发者面板

正常现象。实机查证（v0.0.0.6）：**正式发行版里游戏没有创建调试管理器**
（`DebugOptionsBase.s_debugManager` 为 null），调试面板只是内存里的预制体、从未实例化，
所以发行版没有面板可开 —— 那是开发构建（Editor/Dev Build）的功能，不是补丁没生效。

配置里的「允许激活开发者选项」默认是**关闭**的（按玩家要求）。即使打开，发行版里也只是
把组合键接上、尽力补建管理器，面板对象仍然不可见；不建议为了玩游戏打开它。

## 打开魔女手册以后想退出去，但导航里没有「关闭」怎么办

v0.0.0.7 已修：手册/记录这类**整页界面**现在会自己播报内容，并且按 `Esc` 会直接调用
界面自己的关闭按钮（念「已关闭魔女手册。」）。原因是平台层的「能不能点到」判定被手册
打开时的全屏遮罩骗了，把真的关闭按钮误判成不可达 —— 逐作层绕开它，不去改平台层。

如果按 `Esc` 没反应：
1. 确认补丁版本是 0.0.0.7 以上（看 `LogOutput.log` 的 `loaded v…`）；
2. 确认游戏窗口是前台（先点一下游戏窗口再按）；
3. 仍不行就 `Alt`+`F4` 退出，把 `BepInEx\LogOutput.log` 发来。

## 走到地图页，但不知道能去哪里 / 念出来的地点都点不了

- v0.0.0.8 起：只要这一屏是**游戏要求你选地点**，插件一出现就会念「地图上可前往 N 个地点」并给出编号，
  按 `1`-`9` 直接过去（`PageUp`/`PageDown` 翻页）。
- 如果没有听到「地图上可前往…」，说明这一屏只是**你自己打开手册看地图**（不是剧情在等你选），
  这时候听到的是「1F：会客厅、玄关大厅、…」这样的浏览播报，不需要做选择。
- 如果念了地点、按数字键却没反应：先用方向键或 `Tab` 之外的组合键（`Alt`+`Shift`+`F1`）确认插件还活着
  （能听到导航播报）；仍不行请把 `BepInEx\LogOutput.log` 末尾 200 行发出来，日志里会有
  `MAPCHOICE 扫描 … restr=名单(N) choiceMode=True` 这样的行可以判断插件有没有认出选择态。
- 千万不要在这一屏用 `Esc` 关手册：真的在等你选地点时，关掉会让剧情永远等不到结果。
  插件已经帮你拦住了（会念「请先选择一个地点。」）。

## 审判里要出示证据，我听不到有哪些证物

- **v0.0.0.11 起已支持**：打开证物页后会自动念「请出示证据。可选的证物共 N 件：1、…」。
- 如果只听到「证物 1」「证物 2」这种占位名，说明那一次没读到右侧标题（不影响选择）。
- 选择方式：`1`～`9` 选中 → **回车/空格** 出示 → 确认框按 `1`（返回）或 `2`（是）。
- 出示这一步**故意不自动**：提交哪件证据是玩家的决定，补丁只负责把可选项念清楚。

## 按 Ctrl+Alt+Shift+F3 没有出现开发者面板？

v0.0.0.16 起那个组合键改成**剧情跳转菜单**了。原来的「打开游戏自带开发者面板」
在正式发行版里根本走不通：游戏没有创建调试管理器（`DebugOptionsBase.s_debugManager` 是 null），
调试面板只是内存里从未被实例化的预制体。

现在的用法：先在 cfg 里打开「其它 / 允许剧情跳转（开发者）」，再按组合键；
会念出当前剧本和总数，用 `↑` `↓` 换剧本、`回车` 跳转、`Esc` 退出。

注意这是开发者功能：会跳过你没读过的剧情、破坏存档进度、可能剧透，正式游玩请保持关闭。

### 游戏很卡，有没有省电/省显卡的模式？（v0.0.0.16 起）

有，按 `Alt`+`Shift`+`F2` **一轮一轮往上加**：关闭 → 保守 → 普通 → 激进 → 关闭，每按一次会念出当前档位（v0.0.0.16 起）。也可以在 cfg 的「性能 / 低性能模式档位」里固定一档。
档位是五档：关闭 → 轻度 → 均衡 → 强力 → 极限。测试机上标题画面从 ≈10.5 帧（关闭）
涨到 ≈20.4 帧（强力），「极限」把窗口降到 0.5×、画面整个丢掉只剩黑窗口，另外强制最低 LOD、关掉所有后处理、停掉所有动画。
不喜欢窗口变小可以关掉「性能 / 允许改变窗口分辨率」（0.0.16 起降分辨率算进档位）。
「极限」档不影响操作（它把 UI 颜色刷黑、不是关 Canvas），点击与朗读都还在。
注意收益取决于场景：ADV 对白场景本来就便宜，差别没这么大。回到「关闭」时会把所有改过的画面设置还原。
它会先把**补丁自己的**每帧开销压下去（无视觉代价），再按你的配置降低画面：
URP 画质、柔边阴影、渲染分辨率三档可以单独关。关掉模式会把设置全部还原。

两点说明：
- 帧率低于 15 帧时它会念一句提醒，但**不会自动切换**；
- 画面降级在测试机上没有测出提升（那台机器是主线程瓶颈），所以如果画面变差了、
  帧率没变好，直接把「降低 URP 画质」「关闭柔边阴影」关掉即可。
