# 常见问题

> 发布包内文档之一。**跨作可复用**（玩家遇到的问题高度重复）。
> 逐作只需要补「本作特有」的那几条。

## 装了没反应 / 游戏里一片安静

按顺序排查：

1. **先按 `F7`**。你的机器上可能同时装了 NVDA 和争渡，`语音后端 = 自动` 会按平台顺序
   挑中 NVDA；如果你平时用争渡，就会一句都听不到。按 `F7` 循环切换后端，
   每切一次都会念出新的后端名（`语音后端：争渡读屏` / `语音后端：SAPI` …）。这是 v0.0.0.2 新增的逃生键。
2. **看日志**。`BepInEx\LogOutput.log` 里有没有
   `语音后端就绪` 或 `无障碍补丁已加载`？
   - 完全没有这个文件 → BepInEx 没挂上，检查 `winhttp.dll`
     是不是在**游戏根目录**
   - 有文件但没有插件的行 → 插件版本号可能非法（含字母），
     看日志里有没有 `version is invalid`
3. **语音后端**。把配置里的「语音后端」依次钉死成 `SAPI` 试 ——
   如果 SAPI 能出声，说明是 NVDA 那条路的问题。
   注意：**钉死的后端不可用不会回退**，这是刻意的。
4. **中文语音**。SAPI 需要系统里装了中文语音包，
   否则会念成英文或者干脆不出声。设置 → 时间和语言 → 语音。

## 日志里有一行 `version is invalid`

`BepInPlugin` 的版本号含字母了。BepInEx 会**静默跳过整个插件**。
这不该出现在正式发布版里 —— 请反馈，这是打包 bug。

## 按 Tab 没反应 / 导航键是什么

**主键是 `Alt`+`Shift`+`F1`**（v0.0.0.2 起）。`Tab` 仍可用，但**本作标题画面出现后会
把 Tab 当自己的菜单键吃掉** —— 表现为「主界面加载前按 Tab 有反应、加载后没反应」。
两个键都能在 `BepInEx\config\manosaba.a11y.reader.cfg` 的「界面导航」组里改
（`导航开关键` / `同时允许 Tab`）。改坏了也不用重装：`同时允许 Tab` 留着就能救回来。

进入导航后会听见「导航模式，标题画面，共 5 项。退出游戏，按钮。1 / 5」；
`↑` `↓` 换项、`回车` 激活、再按一次 `Alt`+`Shift`+`F1` 退出。

## 台词朗读和游戏语音叠在一起

**本作是「全部朗读」**：中文文本配日文语音，读屏玩家需要中文，
所以补丁不对「有配音的台词」做静音跳过，语音与朗读会同时出声。

想只听语音（放弃中文朗读）目前**没有开关**。如果这个体验不可接受，
请在反馈里说明你的用法（混合朗读 / 只听语音 / 只听读屏），下一版按需求加开关。

## 标题 / 菜单里的按钮念不出名字，只念类型

v0.0.0.2 已经按实机取证给标题菜单、手机菜单、系统设置、画廊、对话记录里的控件做了中文名
（新游戏 / 读取存档 / 鉴赏模式 / 退出游戏 / 保存 / 读取存档 / 对话记录 / 系统设置 /
返回标题 / 主音量 / 文字显示速度 / 语言 …），滑条会报百分比、下拉框会报当前选项。

但如果某个界面里出现「只念类型、没有名字」，通常是这两类：

1. **魔女手册（WitchBook）的页签与卡片** —— 还没有实机复测，名字可能缺失。
2. **存档槽** —— 220 个槽位文字都是 `<cspace=0.12em>NO DATA`，会被去重成同一句。

这是已知缺口，不是安装错误。

如果某个界面里**所有**控件都念不出来：

1. 打开配置「界面诊断日志」
2. 进那个界面，退出游戏
3. 把 `LogOutput.log` 里 `[UiNav]` 那些行发给我们

那里面是控件名、层级路径与朗读文本，**排查完请关掉**，否则日志会很大。

## 快进的时候不朗读

**这是设计如此** —— 快进期间每一行都念会刷屏。
松手停下来时，补丁会补念停在哪一句（配置「快进停止时补念当前句」）。

## 限时选择来不及选

配置「限时选择时长」可以拉长倒计时（默认比原版长）。

> **倒计时只能拉长，不能取消。** 到点会走「什么都不做」的沉默分支 ——
> 取消掉等于**删掉一个剧情分支**，那不是无障碍该做的事。
> 附注：本作剧本里 `timeout` 出现 0 次，实测**没有限时选项**，这条对当前版本是空转。

## 导航的时候会念到一堆无关的按钮

配置「排除的对象名」里加上那些控件的**对象名**（逗号分隔）。
匹配走**祖先链** —— 填容器的名字就能把里面整棵子树排除掉。

名字要从 `[UiNav]` 诊断日志里**实查**，不要凭感觉猜。

## 存档会被覆盖 / 退出游戏按错

- 「退出前二次确认」默认是开的：激活 `Exit@@ 类控件会先朗读一次确认，
  再按一次回车才真的退出，按方向键即取消。
- 存档槽现在会读「存档名 + 时间 + 章节」拼起来的结果，
  所以同一页的空槽位不会再念成 5 个一样的「无存档」。

## 会不会封号 / 算不算作弊

补丁**不修改游戏文件**，不联网，不注入游戏进程以外的任何东西。
但**请自行判断风险**：这是第三方工具，开发商没有背书。

## 支持盗版吗

**不支持。** 本补丁只面向已通过 Steam 购买本作的玩家。
它的意义是让你**能玩上**这款游戏，不是让你不必买它。

## 第一次启动特别慢 / 卡在启动界面（IL2CPP 特有）

本作是 IL2CPP，BepInEx 6 首次启动要生成 `BepInEx\interop\`（约 160 个程序集），
**几十秒到几分钟**都算正常，画面没反应不等于卡死。第二次启动就恢复正常。

如果一直很慢、或者 `BepInEx\interop\` 里有 **0 字节**的 dll：
关游戏 → 删掉整个 `BepInEx\interop\` → 再启动一次 → 看 `BepInEx\LogOutput.log`。

## 报错里有 `Il2CppInterop.Runtime` / `ClassInjector`（IL2CPP 特有）

说明包里的 `BepInEx\core\Il2CppInterop.Runtime.dll` 与生成 interop 的那份不一致。
把整个 `BepInEx\interop\` 删掉、用本包里的 core 重新启动一次即可。
